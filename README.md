# Interactive Kaleidoscope Patterns

An interactive kaleidoscope visualization created with p5.js that generates symmetrical patterns based on user input.

## Features

- Dynamic pattern generation based on mouse movement or touch
- 12-fold rotational symmetry
- Velocity-based stroke weight for dynamic line thickness
- Trailing effect with gradual fade
- Responsive canvas that adjusts to window size
- HSB color mode with smooth hue transitions
- Mobile-friendly touch controls

## How to Use

1. Move your mouse or touch and drag on mobile devices
2. Watch as symmetrical patterns form and fade
3. The patterns change color gradually over time

## Controls

- Mouse movements on desktop
- Touch swipes on mobile devices
- Resize the window to reset the canvas
